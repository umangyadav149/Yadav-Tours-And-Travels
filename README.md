# 🚗 Yadav Tours & Travels

A responsive travel and car rental website built for **Yadav Tours & Travels**.

The website is designed to showcase travel services, available vehicle categories, customer reviews, trip cost estimation, enquiry functionality, and direct communication options.

## 🌐 Live Website

**[Yadav Tours & Travels](https://yadavtoursandtravels.netlify.app/)**

## 🚀 How to Run Locally

1. Clone the repository.

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in a web browser.

4. Make sure the `images` folder remains in the same project directory.
